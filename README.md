# AI医生智能体 - 前端Demo

这是一个AI医生智能体的前端演示页面，模拟小程序风格的交互界面。

## 功能特性

- 🎨 小程序风格UI设计
- 💬 实时对话交互
- 🤖 AI智能回复
- 📱 响应式设计，支持PC和移动端
- 🎯 用户流程模拟（新用户/老用户）
- 💎 会员权益推荐
- 🔍 功能自动识别

## 文件结构

```
.
├── index.html      # 主页面
├── style.css       # 样式文件
├── app.js          # 交互逻辑
└── README.md       # 说明文档
```

## 使用方法

### 本地运行

直接在浏览器中打开 `index.html` 文件即可。

### GitHub Pages 预览

1. 进入仓库的 Settings
2. 在左侧菜单中找到 Pages
3. 在 Source 部分选择 "GitHub Actions"
4. 保存后，GitHub Actions 会自动部署
5. 部署完成后，可以通过 `https://kehan857.github.io/AI_docker_agent/` 访问

## 功能说明

### 用户类型
- **新用户**：首次使用，会收到30天免费权益推荐
- **老用户**：直接进入AI医生功能介绍

### 主要功能
1. 健康咨询
2. 症状分析
3. 养生建议
4. 科技养生无烟艾灸
5. 深度体检（会员专享）
6. 专家会诊（会员专享）
7. 个性化健康方案（会员专享）

### 交互流程
1. 用户输入问题或选择功能
2. 系统自动识别功能类型（免费/付费/前台服务）
3. 根据用户会员状态提供相应服务入口
4. 非会员用户会收到会员权益推荐
